📖 About

BoneCheats is a feature-packed BONELAB modification built using MelonLoader, BoneLib and LabFusion.

It introduces a custom Cheats menu packed with visual enhancements, combat modifications, movement abilities, player interactions and multiplayer lobby features.

Whether you want to experiment with different gameplay mechanics, customize your experience or explore additional possibilities in BONELAB, BoneCheats brings everything together in one convenient menu.

✨ Highlights

- Extensive collection of gameplay modifications.
- Custom visual enhancements.
- Advanced movement abilities.
- Player and weapon customization.
- Multiplayer lobby utilities.
- Configurable settings.
- Open-source C# project.
- GitHub-based release distribution.

📥 Download & Installation

Latest Version: 1.3.0

"⬇️ Download Latest Release" (https://github.com/UltraAiSlopCode/BoneCheats/releases/latest)

Requirements

Make sure you have the following installed:

- BONELAB (Patch 6)
- MelonLoader
- BoneLib
- LabFusion

Installation

1. Download "BoneCheats.dll" from the "Releases page" (https://github.com/UltraAiSlopCode/BoneCheats/releases/latest).
2. Open your BONELAB installation directory.
3. Navigate to the "Mods" folder.
4. Place "BoneCheats.dll" inside.
5. Make sure all required dependencies are installed.
6. Launch BONELAB.
7. Open the BoneCheats menu and enjoy!

🔨 Building From Source

Want to compile BoneCheats yourself?

Requirements

- Visual Studio 2022 Community Edition
- .NET 6 SDK
- BONELAB
- MelonLoader
- BoneLib
- LabFusion

Build Instructions

1. Clone or download this repository.
2. Open "BoneCheats.sln" in Visual Studio.
3. Copy "BoneCheats.props.user.example" to "BoneCheats.props.user".
4. Configure your BONELAB installation directory.
5. Ensure the required dependencies are available.
6. Select the "Release" configuration.
7. Build the solution.

Output

The compiled DLL should be located at:

BoneCheats/bin/Release/net6.0/BoneCheats.dll
