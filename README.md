# 🦴 BoneCheats AI Slop

**BoneCheats 1.2.0 — BONELAB Mod**

A feature-packed BONELAB mod built with MelonLoader, BoneLib and LabFusion.

BoneCheats adds a custom Cheats menu with visual enhancements, combat modifications, movement abilities, player interactions and lobby features.

## 📥 Downloads

**Latest Release:** [Download BoneCheats.dll](../../releases/latest)

1. Download the latest `BoneCheats.dll` from the Releases page.
2. Place the DLL inside your BONELAB `Mods` folder.
3. Make sure MelonLoader, BoneLib and LabFusion are installed.
4. Launch BONELAB.

## 🔨 Building From Source

**Requirements:**
- Visual Studio 2022
- .NET 6 SDK
- BONELAB
- MelonLoader
- BoneLib
- LabFusion

**Instructions:**

1. Clone or download this repository.
2. Open `BoneCheats.sln` in Visual Studio.
3. Copy `BoneCheats.props.user.example` to `BoneCheats.props.user`.
4. Configure your BONELAB installation directory.
5. Select the `Release` configuration.
6. Build the solution.

The compiled DLL will be located at:

`BoneCheats/bin/Release/net6.0/BoneCheats.dll`
